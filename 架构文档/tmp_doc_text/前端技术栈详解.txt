TanStack Query v5+（以前叫 React Query）是 2026 年 React / Next.js 生态中最主流、最强大的数据获取、缓存、同步、状态管理工具，尤其在 Next.js 15+ App Router + React 19 的全栈应用中，几乎是默认数据层选择。
